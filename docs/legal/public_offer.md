## 3. Порядок оформления бронирования

3.1. Пользователь может оформить бронирование оборудования или заказ товара через сайт sportgearhub.ru.
3.2. Для оформления бронирования пользователь предоставляет минимальные данные:

- имя или ФИО

3.3. Данные пользователя передаются партнёру платформы для исполнения бронирования или заказа.
